# Student Performance Analysis

## 📌 Project Overview

This project performs Exploratory Data Analysis (EDA) on student exam performance data.

The analysis focuses on Mathematics, Reading, and Writing scores and explores how student performance varies across different demographic and educational factors.

## 🎯 Objectives

- Understand the structure and quality of the dataset
- Analyze student score distributions
- Compare average scores across different groups
- Analyze the impact/association of test preparation status with scores
- Explore performance patterns across parental education and lunch categories
- Identify useful insights from the data
- Perform basic data quality checks

## 🛠️ Technologies Used

- Python
- NumPy
- Pandas
- Matplotlib
- Jupyter Notebook

## 📊 Dataset

The dataset contains student information and their scores in:

- Mathematics
- Reading
- Writing

The analysis also includes categorical information such as:

- Gender
- Parental level of education
- Lunch category
- Test preparation course

## 🔍 Analysis Performed

### 1. Dataset Overview
- Dataset shape
- Column names
- Data types
- Missing values
- Descriptive statistics

### 2. Score Analysis
- Subject-wise average scores
- Score distributions
- Comparison of Mathematics, Reading and Writing performance

### 3. Categorical Analysis
- Gender-wise performance
- Test preparation course comparison
- Parental education comparison
- Lunch category comparison

### 4. Data Quality
- Missing value check
- Duplicate record check
- Score range validation
- Category value inspection

## 📈 Key Findings

The analysis identifies differences in average student performance across subjects and between different categories such as gender, test preparation status, parental education and lunch type.

The detailed numerical findings and visualizations are available in the Jupyter Notebook.
